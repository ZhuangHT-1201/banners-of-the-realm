# Contributing to Banners of the Realm

Thanks for taking an interest in the project.

## Before opening a pull request

1. Run `npm test`.
2. Run `npm run build`.
3. Keep the game asset-free: new visuals and sounds should continue to be generated in code unless there is a strong, documented reason otherwise.
4. Describe any gameplay, balance, accessibility, or historical-design impact in the pull request.

## Repository access

The repository owner and maintainer is [@ZhuangHT-1201](https://github.com/ZhuangHT-1201). Write access is intentionally limited to the maintainer. Automated coding agents and bot accounts, including Cursor-related accounts, are not added as collaborators.

Contributions are accepted through public pull requests so that all changes remain reviewable and attributable.
